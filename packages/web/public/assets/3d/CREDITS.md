# 3D asset credits

All third-party assets in this folder are public domain (CC0 1.0).

- `furniture/`, `plants/`, `textures/` — [Poly Haven](https://polyhaven.com) models and textures (CC0), some meshes
  simplified for real-time use.
- `city/` — [Kenney](https://kenney.nl) City Kit (Commercial, Roads, Suburban) and Car Kit (CC0).
- `humans/` — characters generated with MPFB / MakeHuman system assets (CC0).
