# UI spec — packages/web/src/ui

## Design system
Dark glass panels floating over the world. Tokens (CSS custom properties on `.ao-root`):
- Surfaces: `--bg` rgba(15,20,30,.88), `--bg-solid` rgba(17,22,33,.98), `--bg-soft` rgba(255,255,255,.04),
  `--bg-hover` rgba(255,255,255,.07); lines `--line` rgba(148,163,184,.16), `--line-strong` rgba(148,163,184,.28).
- Text `--text` #e7ecf3, `--muted` #9aa6b8, `--faint` #8a96aa. Brand `--brand` #2f6fed, accent `--accent` #6ea2ff,
  `--accent-soft` rgba(79,134,247,.16).
- Status: working #3ecf8e, waiting #f5b544, shell #38c9d3, idle #8d99ad, done #6ea2ff, error #ef6b6b.
- Radius 12 / 8 px; shadow `0 10px 30px rgba(3,7,15,.35)`; font: system UI stack (Inter if available), 13 px base;
  numbers tabular. Thin line icons (SVG, 1.75 stroke, currentColor) for every button.
- Motion: 150-250 ms ease-out for panels/toasts; respect prefers-reduced-motion.
- Layout: top bar (56 px); left sidebar (320 px, collapsible); right drawer (380 px, slides in); bottom feed (collapsible
  bar, expands to ~200 px); toasts bottom-right above the feed; popovers anchored to their buttons. Panels never cover
  the world entirely; the world camera focuses into the free area (the world API receives insets).
- Narrow screens (< 900 px): sidebar and drawer become overlays with a scrim.

## Brand
Logo: rounded square (brand blue) with a minimal tower/building glyph. Wordmark: "AI Office" ("AI " in text color,
"Office" in accent), 700 weight. Page title "AI Office"; with alerts "(n) AI Office". Favicon from the logo.

## Components
Store (SSE client with reconnection backoff 2 s to 30 s, mock mode via shared demo simulator, message client, history/
transcript fetchers), TopBar, Sidebar, Drawer (AgentView with tabs, RoomView), Feed, Toasts, NotificationCenter,
MessageComposer, PermissionCard, TerminalPanel (read-only), SessionHistory popover, DayDialog, Settings popover, Help
dialog, Splash ("Conectando ao escritório…"), Connection banner, Empty state ("Nenhuma sessão aberta" + how to start +
demo toggle), HoverTip over the world. Preferences persisted in localStorage `ai-office:prefs` (validated on load).

## Accessibility
Keyboard shortcuts as in 00-product.md; focus-visible rings; aria labels on icon buttons; live region for
announcements; color is never the only signal (status also has text).
